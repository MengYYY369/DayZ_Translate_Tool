## Goal

给 `DayZ_Translate_Tool` 加一个**命令行入口** `python cli.py <命令> [参数]`，让 AI（和人）不开窗口就能：

1. 看懂一份 stringtable.csv（`inspect`）；
2. 按界面里配好的翻译源把表格翻译好（`translate`）——**默认一个字节都不动原文件**，结果先落到预览文件；
3. 直接改表格内容（`edit`：改格子 / 批量查找替换 / 加行 / 删行）；
4. 从 config.cpp 把缺的键补进表格（`keys`）；
5. 读写术语词表（`wordbook`）；
6. 测源、加源、删源、调顺序、改勾选规则（`sources`）；
7. 看缓存、清缓存（`cache`）。

**最关键的一条：命令行和界面共用同一套逻辑、同一份配置。** 界面里配好的源、密钥、顺序、勾选规则，命令行直接沿用；命令行改的配置写回同一份配置，界面重开就生效。

## Architecture

### 数据流

```text
                    ┌──────────────────────────────┐
                    │  QSettings（注册表）           │
                    │  translation_sources_json     │
                    │  source_header / char_budget  │
                    │  translation_timeout          │
                    └───────┬──────────────┬────────┘
                            │              │
              ┌─────────────▼───┐   ┌──────▼──────────────┐
              │ main.py（窗口）  │   │ cli.py（命令行）     │
              │  QTableWidget   │   │  list[list[str]]    │
              └───────┬─────────┘   └──────┬──────────────┘
                      │                    │
                      └────────┬───────────┘
                               ▼
                    translation_flow.py（共用编排层）
                    ├─ load_app_settings() / save_sources()
                    ├─ fill_copy_columns()      ← original/chinese 复制列
                    ├─ collect_jobs()           ← 四种模式挑任务
                    ├─ build_translation_configs() ← 按规则过滤源 → TranslatorConfig
                    ├─ run_translation()        ← TranslationService 主备降级
                    ├─ apply_results() / failed_cells()
                    └─ build_glossary()         ← 词表 → 术语表
                               │
                               ▼
                    translator_service.py（不动）
```

命令行翻译一次的完整流程：

```text
python cli.py translate a.csv --mode empty --write
  ↓
load_dayz_csv(a.csv)                      → headers, rows, warnings
  ↓
translation_flow.load_app_settings()      → 界面那份配置
  ↓
fill_copy_columns(headers, rows)          → original←english、chinese←chinesesimp
  ↓
collect_jobs(headers, rows, ...)          → [(row, column, text, target_code), ...]
  ↓
build_translation_configs(...)            → [TranslatorConfig, ...]（按规则勾选的源，按列表顺序）
  ↓
run_translation(jobs, configs, ...)       → TranslationResults（主备降级在 service 里）
  ↓
apply_results(rows, results)              → 新 rows
  ↓
--write ? 备份 a.csv.bak + 写回 a.csv : 写 a.preview.csv
  ↓
摘要打屏（--json 时打 JSON）+ 失败行清单 + 退出码
```

### 命令契约（最终版，实现必须与这里一字不差）

```text
python cli.py inspect <csv> [--json]
python cli.py translate <csv> [--mode empty|all|columns|rows] [--columns a,b]
                   [--rows 3,5-9] [--only-empty] [--source ID] [--from-column HEADER]
                   [--wordbook PATH] [--preview PATH] [--write] [--quiet] [--json]
python cli.py edit set-cell <csv> --row N --column HEADER --text "..." [--write] [--preview PATH] [--json]
python cli.py edit replace  <csv> --column HEADER --find X --replace Y
                   [--regex] [--ignore-case] [--whole-word] [--write] [--preview PATH] [--json]
python cli.py edit add-row    <csv> --key NAME [--after N] [--write] [--preview PATH] [--json]
python cli.py edit delete-row <csv> (--row N | --key NAME) [--write] [--preview PATH] [--json]
python cli.py keys <csv> --from <config.cpp|文件夹> [--from ...] [--write] [--preview PATH] [--json]
python cli.py wordbook list [--wordbook PATH] [--json]
python cli.py wordbook set --original X --language chinesesimp --text 刀 [--wordbook PATH] [--json]
python cli.py wordbook remove --original X [--wordbook PATH] [--json]
python cli.py wordbook import <csv> [--wordbook PATH] [--json]
python cli.py wordbook export <csv> [--wordbook PATH] [--json]
python cli.py sources list [--json]
python cli.py sources test [--source ID] [--wordbook PATH] [--json]
python cli.py sources add-ai --name X --type openai [--base-url URL] [--model M] [--key K]
                   [--concurrency N] [--interval S] [--rules all,empty,selection] [--json]
python cli.py sources remove <id> [--json]
python cli.py sources move <id> (--up | --down) [--json]
python cli.py sources set-rule <id> --rules all,empty,selection [--json]
python cli.py sources set-key <id> --key K [--json]
python cli.py cache stats [--json]
python cli.py cache clear [--json]
```

**行号规矩**：`--row` / `--rows` 全部是**数据行号，从 1 开始，不含表头**。`inspect` 打印的行号也是这一套。`--rows 3,5-9` 支持逗号和区间。**越界的行号一律退出码 `2` 报错**，`translate` 和 `edit` 行为一致（不会静默跳过）。

**列名规矩**：`--column` / `--columns` 既认表头名（`chinesesimp`），也认语言代码（`zh-CN`），大小写不敏感。`translate` 的 `--columns` 可以给多列；`edit` 的 `--column` **只能给一列**，给多列报错退出码 `2`（否则会静默只改排序最前的那列）。

**`--preview` 不能指回原文件**：指回去报错退出码 `2` —— 不加 `--write` 就承诺原文件一字不动，写回原文件请用 `--write`（带 `.bak` 备份）。

**`edit add-row` 必须给 `--key`**：整行全空的行保存时会被丢掉，不给键名就加不出东西来，直接报错退出码 `2`。

**退出码**：`0` = 成功；`1` = 部分失败（有没翻好的行）；`2` = 彻底失败（参数错、文件读不了、没有任何可用源）。

**输出规矩**：结果走 stdout（`--json` 时是 JSON），进度日志走 stderr。JSON 顶层统一信封：

```json
{"ok": true, "command": "translate", "file": "D:/x/stringtable.csv",
 "data": { ... }, "warnings": [], "errors": []}
```

`--write` 保护只加在**会动数据文件**的命令上（`translate`、`edit`、`keys`）。改配置（`sources`）、改词表（`wordbook`）、清缓存（`cache`）**直接生效**——理由：前者弄坏了要重翻一遍，后者弄坏了改回来就行。

**`--json` / `--quiet` 每个子命令都有**：上面契约只在 `translate` 那行写全了。`--json` 让结果走 stdout 的 JSON；`--quiet` 只压掉 stderr 的进度日志（JSON 结果照常打印）。

**「另存为 / 只导出」没有单独的命令**：它就是「不加 `--write` + `--preview PATH`」——原文件一字不动，结果写到指定路径（不指定就是原文件名加 `.preview.csv`）。

# —— 复制列 ——

def fill_copy_columns(headers, rows, overwrite=False, row_indexes=None):
    """把 original←english、chinese←chinesesimp 这些复制列填上。

    返回 `(新行列表, 有没有改动)`；输入 rows 不会被改。
    """
    filled = [list(row) for row in rows]
    changed = False
    targets = range(len(filled)) if row_indexes is None else sorted(row_indexes)
    for column_index, header in enumerate(headers):
        source_header = copy_source_for_header(header)
        if not source_header:
            continue
        try:
            source_column = header_index(headers, source_header)
        except ValueError:
            continue
        for row_index in targets:
            if row_index < 0 or row_index >= len(filled):
                continue
            row = filled[row_index]
            source_text = _text_at(row, source_column)
            if not source_text:
                continue
            existing = _text_at(row, column_index)
            if existing and not overwrite:
                continue
            if existing == source_text:
                continue
            _set_at(row, column_index, source_text)
            changed = True
    return filled, changed


# —— 挑任务 ——

def collect_jobs(headers, rows, source_header, mode=MODE_EMPTY, columns=None,
                 row_indexes=None, only_empty=False):
    """按模式挑出翻译任务：`[(行下标, 列下标, 原文, 目标语言码), ...]`。

    - `MODE_EMPTY`：整张表，但只翻目标格还空着的（就是界面上的「翻译空白单元格」）
    - `MODE_ALL`：整张表，已有译文的也重翻
    - `MODE_COLUMNS`：只翻 `columns` 里的列
    - `MODE_ROWS`：只翻 `row_indexes` 里的行

    `row_indexes` / `columns` 在四种模式下都再收窄一次范围：`None` = 没给（全都要），
    给了个空集合 = 一个都不要（返回空任务表）；`only_empty=True` 可以在任何模式下再叠
    一层「只翻空格」。
    """
    if mode not in ALL_MODES:
        raise ValueError(f"Unknown mode: {mode}")
    # 界面上「一行都没选中」时会传一个空集合进来（不是 None）—— 那时不能抛错：原行为是
    # 照样填复制列，然后由 run_translation_jobs 弹一句「没有可翻译的选中单元格」。
    # 所以这里只把 None 当成「参数没给」。
    if mode == MODE_ROWS and row_indexes is None:
        raise ValueError("--rows is required when --mode rows")
    if mode == MODE_COLUMNS and columns is None:
        raise ValueError("--columns is required when --mode columns")
    selected_rows = sorted(set(row_indexes)) if row_indexes is not None else range(len(rows))
    selected_columns = set(columns) if columns is not None else None
    if mode == MODE_COLUMNS:
        jobs = build_column_translation_jobs(headers, rows, source_header, selected_columns)
        if row_indexes is not None:
            wanted = set(selected_rows)
            jobs = [job for job in jobs if job[0] in wanted]
    else:
        jobs = build_row_translation_jobs(headers, rows, source_header, selected_rows,
                                          selected_columns)
    if mode == MODE_EMPTY or only_empty:
        jobs = [job for job in jobs if not _text_at(rows[job[0]], job[1])]
    return jobs

def build_source_config(entry, char_budget=None, timeout=None, label=None, glossary=None,
                        glossary_source_key=""):
    """一条源 → 一份 TranslatorConfig。字段取值与界面上的 build_source_config 完全一致。"""
    from translator_service import TranslatorConfig

    if label is None:
        label = entry.name or entry.source_id
    budget = DEFAULT_CHAR_BUDGET if char_budget is None else int(char_budget)
    limit = DEFAULT_TIMEOUT if timeout is None else float(timeout)
    glossary = list(glossary or [])
    glossary_source_key = (glossary_source_key or "").strip().lower()
    if entry.is_ai:
        return TranslatorConfig(
            provider=entry.api_type or "openai",
            label=label,
            char_budget=budget,
            parallel_batches=max(1, int(entry.concurrency or 1)),
            min_interval=max(0.0, float(entry.interval or 0.0)),
            api_key=entry.api_key,
            model=entry.model,
            base_url=entry.base_url,
            timeout=limit,
            glossary=glossary,
            glossary_source_key=glossary_source_key,
        )
    spec = FREE_SOURCE_SPECS.get(entry.source_id, {})
    return TranslatorConfig(
        provider=entry.source_id,
        label=label,
        char_budget=budget,
        parallel_batches=max(1, int(spec.get("concurrency", 1) or 1)),
        min_interval=max(0.0, float(spec.get("interval", 0.0) or 0.0)),
        api_key=entry.api_key,
        timeout=limit,
        glossary=glossary,
        glossary_source_key=glossary_source_key,
    )


def build_translation_configs(sources, rule, char_budget=None, timeout=None, glossary=None,
                              glossary_source_key="", source_id=None, label_for=None):
    """按勾选规则挑源 → 一串 config。`source_id` 非空时只留这一条（本次命令临时覆盖）。"""
    entries = sources.candidates(rule)
    if source_id:
        known = sources.find(source_id)
        if known is None:
            raise ValueError(f"Unknown source id: {source_id}")
        entries = [entry for entry in entries if entry.source_id == source_id]
    return [
        build_source_config(
            entry, char_budget=char_budget, timeout=timeout,
            label=(label_for(entry) if label_for else None),
            glossary=glossary, glossary_source_key=glossary_source_key,
        )
        for entry in entries
    ]


# —— 跑翻译 ——

def build_service(cache=None, retry_policy=None):
    service = TranslationService(cache=cache if cache is not None else {})
    if retry_policy is not None:
        service.retry_policy = retry_policy
    return service


def run_translation(raw_jobs, configs, source_header, cache=None, progress_callback=None,
                    should_cancel=None, on_fallback=None, retry_policy=None):
    """把 `collect_jobs()` 的输出交给 TranslationService（主备降级在 service 里）。"""
    jobs = [
        TranslationJob(row, column, text, source_language_code_for_header(source_header), target)
        for row, column, text, target in raw_jobs
    ]
    service = build_service(cache=cache, retry_policy=retry_policy)
    return service.translate_jobs_with_fallback(
        jobs, configs, progress_callback=progress_callback,
        should_cancel=should_cancel, on_fallback=on_fallback,
    )


def apply_results(headers, rows, results):
    """把 `results.cell_results` 写回行数据；越界的格子丢掉。"""
    updated = [list(row) for row in rows]
    for (row_index, column_index), text in results.cell_results.items():
        if row_index < 0 or row_index >= len(updated):
            continue
        _set_at(updated[row_index], column_index, text)
    return updated


def failed_cells(raw_jobs, results):
    """没拿到译文的格子，保持输入顺序。"""
    return [(row, column) for row, column, _text, _target in raw_jobs
            if (row, column) not in results.cell_results]


# —— 术语表 ——

def build_glossary(wordbook_rows):
    """词表行 → 术语表；至少两列有值才算一条（跟界面上的 wordbook_glossary 一致）。"""
    from wordbook_csv import WORDBOOK_HEADERS

    glossary = []
    for row in wordbook_rows:
        item = {}
        for column_index, value in enumerate(row):
            value = (value or "").strip()
            if value and column_index < len(WORDBOOK_HEADERS):
                item[WORDBOOK_HEADERS[column_index]] = value
        if len(item) >= 2:
            glossary.append(item)
    return glossary


# —— 小工具 ——

def _text_at(row, column_index):
    if column_index < 0 or column_index >= len(row):
        return ""
    return (row[column_index] or "").strip()


def _set_at(row, column_index, text):
    if column_index < 0:
        return
    while len(row) <= column_index:
        row.append("")
    row[column_index] = text

class Reporter:
    """结果走 stdout，进度日志走 stderr。"""

def parse_rows(text):
    """`'3,5-9'` → `[3, 5, 6, 7, 8, 9]`（数据行号，从 1 开始；去重升序）。"""
    rows = set()
    for part in str(text or "").split(","):
        part = part.strip()
        if not part:
            continue
        if "-" in part:
            start_text, _sep, end_text = part.partition("-")
            try:
                start, end = int(start_text), int(end_text)
            except ValueError:
                raise CliError(f"bad row range: {part}")
            if start < 1 or end < start:
                raise CliError(f"bad row range: {part}")
            rows.update(range(start, end + 1))
        else:
            try:
                value = int(part)
            except ValueError:
                raise CliError(f"bad row number: {part}")
            if value < 1:
                raise CliError(f"bad row number: {part}")
            rows.add(value)
    if not rows:
        raise CliError("no rows given")
    return sorted(rows)


def resolve_columns(headers, text):
    """`'chinesesimp,zh-CN'` → 列下标列表。既认表头名，也认语言代码，**都不区分大小写**。

    语言代码有歧义时（`chinese` 和 `chinesesimp` 都映射 `zh-CN`）直接报错并列出候选列名，
    不替用户瞎猜。
    """
    indexes = []
    for part in str(text or "").split(","):
        part = part.strip()
        if not part:
            continue
        try:
            indexes.append(header_index(headers, part))
            continue
        except ValueError:
            pass
        wanted = part.lower()
        matches = [index for index, header in enumerate(headers)
                   if (language_code_for_header(header) or "").lower() == wanted]
        if not matches:
            raise CliError(f"unknown column: {part}")
        if len(matches) > 1:
            names = ", ".join(headers[index] for index in matches)
            raise CliError(f"column {part} is ambiguous, it matches: {names}")
        indexes.append(matches[0])
    if not indexes:
        raise CliError("no columns given")
    return sorted(set(indexes))


def _single_column(headers, text):
    """`edit` 的命令一次只改一列。

    `--column english,chinesesimp` 会被 `resolve_columns` 排成 `[2, 14]`，再取 `[0]`
    就变成「静默只改 english」—— 直接报错比让 AI 以为两列都改了安全。
    """
    indexes = resolve_columns(headers, text)
    if len(indexes) > 1:
        names = ", ".join(headers[index] for index in indexes)
        raise CliError(f"this command takes one column, got: {names}")
    return indexes[0]


def parse_rules(text):
    """`'all,empty'` → `['all', 'empty']`；不写就默认 `['selection']`。"""
    if text is None:
        return ["selection"]
    rules = [part.strip() for part in str(text).split(",") if part.strip()]
    for rule in rules:
        if rule not in ALL_RULES:
            raise CliError(f"unknown rule: {rule} (choose from {', '.join(ALL_RULES)})")
    return rules


def load_table(path):
    if not Path(path).exists():
        raise CliError(f"file not found: {path}")
    headers, rows, warnings = load_dayz_csv(path)
    if not headers:
        raise CliError(f"not a DayZ stringtable csv: {path}")
    return headers, rows, warnings


def default_preview_path(path):
    path = Path(path)
    return path.with_name(f"{path.stem}.preview{path.suffix}")


def apply_changes(args, reporter, path, headers, rows, data):
    """统一出口：`--write` 就备份后写回，否则只写预览文件。"""
    if getattr(args, "write", False):
        backup = Path(f"{path}.bak")
        shutil.copy2(path, backup)
        write_dayz_csv(path, headers, rows)
        reporter.info(f"wrote {path} (backup: {backup})")
        data.update({"written": True, "backup": str(backup), "preview": None})
    else:
        preview = Path(args.preview) if getattr(args, "preview", None) else default_preview_path(path)
        if Path(preview).resolve() == Path(path).resolve():
            # 不加 --write 就承诺原文件一字不动；预览路径指回原文件会静默覆盖且不留备份
            raise CliError("--preview must not point at the source file; pass --write to overwrite it")
        write_dayz_csv(preview, headers, rows)
        reporter.info(f"preview: {preview} (original file untouched; pass --write to save)")
        data.update({"written": False, "backup": None, "preview": str(preview)})
    return data


# —— inspect ——

def cmd_inspect(args, reporter):
    path = Path(args.file)
    headers, rows, warnings = load_table(path)
    settings = flow.load_app_settings()
    columns = []
    for index, header in enumerate(headers):
        if index == 0 or not header.strip():
            continue
        code = language_code_for_header(header)
        if not code:
            continue
        translated = sum(1 for row in rows if _cell(row, index))
        columns.append({
            "index": index,
            "header": header,
            "language": code,
            "translated": translated,
            "empty": len(rows) - translated,
        })
    try:
        source_index = header_index(headers, settings.source_header)
    except ValueError:
        source_index = None
    missing_source = [index + 1 for index, row in enumerate(rows)
                      if source_index is None or not _cell(row, source_index)]
    empty_rows = [index + 1 for index, row in enumerate(rows) if not any(_cell(row, i) for i in range(len(headers)))]
    data = {
        "headers": list(headers),
        "rows": len(rows),
        "source_header": settings.source_header,
        "columns": columns,
        "rows_missing_source": missing_source,
        "empty_rows": empty_rows,
    }
    lines = [f"file: {path}", f"rows: {len(rows)}", f"source column: {settings.source_header}"]
    for item in columns:
        lines.append(f"  {item['header']:<14} {item['language']:<8} "
                     f"translated {item['translated']} / empty {item['empty']}")
    lines.append(f"rows missing source text: {_join(missing_source)}")
    lines.append(f"empty rows: {_join(empty_rows)}")
    reporter.emit(envelope("inspect", path, data, warnings), "\n".join(lines))
    return EXIT_OK


def _cell(row, index):
    if index < 0 or index >= len(row):
        return ""
    return (row[index] or "").strip()


def _join(values):
    return ", ".join(str(value) for value in values) if values else "(none)"

def build_parser():
    parser = argparse.ArgumentParser(prog="cli.py", description="DayZ Translate Tool command line")
    subparsers = parser.add_subparsers(dest="command", required=True)

    inspect_parser = subparsers.add_parser("inspect", help="show what is inside a stringtable csv")
    inspect_parser.add_argument("file")
    _add_json(inspect_parser)
    inspect_parser.set_defaults(handler=cmd_inspect)
    return parser


def _add_json(parser):
    parser.add_argument("--json", action="store_true", help="print the result as JSON")
    parser.add_argument("--quiet", action="store_true", help="do not print progress logs")


def main(argv=None):
    parser = build_parser()
    args = parser.parse_args(argv)
    reporter = Reporter(json_mode=getattr(args, "json", False), quiet=getattr(args, "quiet", False))
    try:
        return args.handler(args, reporter)
    except CliError as exc:
        print(f"error: {exc}", file=sys.stderr)
        return EXIT_FAIL
    except ValueError as exc:
        print(f"error: {exc}", file=sys.stderr)
        return EXIT_FAIL
    except KeyboardInterrupt:
        print("cancelled", file=sys.stderr)
        return EXIT_FAIL


if __name__ == "__main__":
    sys.exit(main())

        for value in parse_rows(args.rows):
            if value > len(rows):
                raise CliError(f"row out of range: {value} (file has {len(rows)} data rows)")
            row_indexes.append(value - 1)
    jobs = flow.collect_jobs(headers, rows, source_header, mode=args.mode,
                             columns=columns, row_indexes=row_indexes, only_empty=args.only_empty)
    reporter.info(f"jobs: {len(jobs)}")
    glossary = flow.build_glossary(_load_wordbook_rows(args.wordbook))
    try:
        configs = flow.build_translation_configs(
            settings.sources, flow.rule_for_mode(args.mode),
            char_budget=settings.char_budget, timeout=settings.timeout,
            glossary=glossary, glossary_source_key=source_header, source_id=args.source)
    except ValueError as exc:
        raise CliError(str(exc))
    if not configs:
        raise CliError("no translation source is enabled for this mode "
                       "(check the rules in Settings, or pass --source)")
    data = {"rows": len(rows), "jobs": len(jobs)}
    if not jobs:
        # 没有任务时原文件不可能变，所以不写预览文件；字段和正常分支保持同一套
        data.update({"translated": 0, "failed": 0, "cache_hits": 0, "failed_cells": [],
                     "errors": [], "written": False, "backup": None, "preview": None})
        reporter.emit(envelope("translate", path, data, warnings), "nothing to translate")
        return EXIT_OK

    cache_store = make_cache_store()
    cache = cache_store.load()
    results = flow.run_translation(
        jobs, configs, source_header, cache=cache,
        progress_callback=lambda results: reporter.info(
            f"translated {results.translated}, failed {results.failed}, cache hits {results.cache_hits}"),
        on_fallback=lambda previous, current: reporter.info(f"fallback: {previous} -> {current}"),
    )
    cache_store.save(cache)
    rows = flow.apply_results(headers, rows, results)
    failed = flow.failed_cells(jobs, results)
    failed_set = set(failed)
    data.update({
        "translated": results.translated,
        "failed": len(failed),
        "cache_hits": results.cache_hits,
        "failed_cells": [
            {"row": row + 1, "column": column, "header": headers[column] if column < len(headers) else "",
             "text": text}
            for row, column, text, _target in jobs if (row, column) in failed_set
        ],
        "errors": results.errors[:5],
    })
    apply_changes(args, reporter, path, headers, rows, data)
    if data["written"]:
        where = f"wrote {path} (backup: {data['backup']})"
    else:
        where = f"preview {data['preview']}"
    text = f"translated {results.translated}, failed {len(failed)}, {where}"
    # 有翻不出来的格子就算部分失败，信封里也要能看出来（只看 ok 的 AI 不会误判成功）
    errors = [f"{len(failed)} cell(s) failed"] if failed else []
    reporter.emit(envelope("translate", path, data, warnings, errors=errors), text)
    return EXIT_PARTIAL if failed else EXIT_OK

def cmd_edit_replace(args, reporter):
    path = Path(args.file)
    headers, rows, warnings = load_table(path)
    column = _single_column(headers, args.column)
    flags = re.IGNORECASE if args.ignore_case else 0
    pattern = args.find if args.regex else re.escape(args.find)
    if args.whole_word:
        pattern = rf"\b{pattern}\b"
    try:
        regex = re.compile(pattern, flags)
    except re.error as exc:
        raise CliError(f"bad pattern: {exc}")
    changes = []
    for row_index, row in enumerate(rows):
        before = _cell(row, column)
        if not before:
            continue
        after = regex.sub(args.replace, before)
        if after == before:
            continue
        _set_cell(row, column, after)
        changes.append({"row": row_index + 1, "column": column, "header": headers[column],
                        "before": before, "after": after})
    data = {"changes": changes, "count": len(changes)}
    apply_changes(args, reporter, path, headers, rows, data)
    reporter.emit(envelope("edit replace", path, data, warnings), f"replaced {len(changes)} cell(s)")
    return EXIT_OK


def cmd_edit_add_row(args, reporter):
    path = Path(args.file)
    headers, rows, warnings = load_table(path)
    if not args.key:
        # 整行全空的行保存时会被 dayz_rows_for_save 丢掉，不给键名就加不出东西来 ——
        # 与其报一个盘上不存在的 added_row，不如直接报错。
        raise CliError("edit add-row needs --key")
    new_row = [""] * len(headers)
    _set_cell(new_row, 0, args.key)
    if args.after is None:
        rows.append(new_row)
        position = len(rows)
    else:
        if args.after < 0 or args.after > len(rows):
            raise CliError(f"--after out of range: {args.after}")
        rows.insert(args.after, new_row)
        position = args.after + 1
    data = {"added_row": position, "key": args.key or ""}
    apply_changes(args, reporter, path, headers, rows, data)
    reporter.emit(envelope("edit add-row", path, data, warnings), f"added row {position}")
    return EXIT_OK


def cmd_edit_delete_row(args, reporter):
    path = Path(args.file)
    headers, rows, warnings = load_table(path)
    if args.row is not None and args.key is not None:
        raise CliError("edit delete-row takes --row or --key, not both")
    if args.row is not None:
        if args.row < 1 or args.row > len(rows):
            raise CliError(f"row out of range: {args.row} (file has {len(rows)} data rows)")
        indexes = [args.row - 1]
    elif args.key is not None:
        indexes = [index for index, row in enumerate(rows) if _cell(row, 0) == args.key]
        if not indexes:
            raise CliError(f"no row with key: {args.key}")
    else:
        raise CliError("edit delete-row needs --row or --key")
    deleted = [{"row": index + 1, "key": _cell(rows[index], 0)} for index in indexes]
    for index in sorted(indexes, reverse=True):
        del rows[index]
    data = {"deleted": [item["key"] for item in deleted], "rows": deleted}
    apply_changes(args, reporter, path, headers, rows, data)
    reporter.emit(envelope("edit delete-row", path, data, warnings),
                  f"deleted {len(deleted)} row(s)")
    return EXIT_OK


def _set_cell(row, column, text):
    while len(row) <= column:
        row.append("")
    row[column] = text

def cmd_wordbook_import(args, reporter):
    from wordbook_csv import WORDBOOK_HEADERS, load_wordbook_csv, write_wordbook_csv

    path = _wordbook_path(args)
    source = Path(args.file)
    if not source.exists():
        raise CliError(f"file not found: {source}")
    _headers, incoming = load_wordbook_csv(source)
    _headers, rows = load_wordbook_csv(path) if path.exists() else (list(WORDBOOK_HEADERS), [])
    known = {(row[0] or "").strip(): row for row in rows}
    imported = 0
    for row in incoming:
        original = (row[0] or "").strip()
        if not original:
            continue
        target = known.get(original)
        if target is None:
            target = [""] * len(WORDBOOK_HEADERS)
            target[0] = original
            rows.append(target)
            known[original] = target
        for column in range(1, min(len(row), len(WORDBOOK_HEADERS))):
            value = (row[column] or "").strip()
            if value:
                _set_cell(target, column, value)
        imported += 1
    path.parent.mkdir(parents=True, exist_ok=True)
    write_wordbook_csv(path, rows)
    data = {"wordbook": str(path), "imported": imported, "count": len(rows)}
    reporter.emit(envelope("wordbook import", path, data), f"imported {imported} entr(ies)")
    return EXIT_OK

## 已知取舍与局限

- **`--write` 会覆盖原文件**（先存 `.bak`）。AI 拿到 `--write` 就等于拿到了写文件的权力，这是用户明确要的（第 2 轮 Q3）。第一次用建议先不加 `--write`，看预览文件对不对。
- **预览文件不会被自动清理**，会一直躺在原文件旁边（`xxx.preview.csv`）。刻意不做自动删除：AI 可能还要读它。
- **`translate` 的失败原因只有引擎级的一份**（`results.errors`），没有「第几行第几列为什么失败」。因为底层 `TranslationService` 就是这么记账的（`_record_failed_batch` / `_record_failed_jobs` 只往 `results.errors` 里塞一句话）。失败清单靠 `(行, 列)` 反推，能说清「哪些格子没翻好」，说不清「每个格子为什么没翻好」。
- **改配置不管界面开没开**：命令行写完配置，界面上那份还是内存里的旧值。**界面必须重开才生效**（用户已确认，第 3 轮 Q3）。命令行写完会在提示里说这句话。
- **一次只处理一个文件**（用户已确认，第 3 轮 Q2）。多文件/文件夹批量不做。
- **不做 MCP 插件、不打包 exe**（用户已确认）。要打包的话得把 `cli.py` 也塞进 PyInstaller 的入口，那是另一件事。
- **`sources test` 会真的发网络请求**（四个语言 = 至少 4 次请求），但**不写缓存** —— 跟界面的「测试这个源」一样，结果只在内存里看一眼，不落盘。
- **`wordbook` 命令直接改词表文件**，没有 `--write` 保护（用户已确认）。词表改坏了改回来就行，而且它同时被界面和命令行共用。
- **`edit replace` 默认区分大小写**，要模糊匹配得显式加 `--ignore-case`。默认从严，免得 AI 一把改掉不该改的格子。
- **`edit add-row` 只填 Language 列**，其他列全是空的，等后面 `translate` 去填。
- **`--source` 只是「本次命令只用一个源」**，不改界面配置。而且这个源必须已经勾了对应规则（`--mode empty` 要勾「翻译空白」），没勾就是「没有可用源」退出码 2。
- **`main.py` 的改动是纯搬家**（Task 2），不改行为。如果发现搬不动（某处逻辑与 `translation_flow` 不等价），就地停下报告，不要为了搬家而改行为。
